## Antresol analytics

### Требования
Убедитесь, что у вас установлены:
* **[uv](https://docs.astral.sh/uv/)** — для управления зависимостями Python.
* **Docker** и **Docker Compose** — для поднятия базы данных.
* **Make** — для удобного выполнения команд.

### Шаги установки

**1. Склонируйте репозиторий и перейдите в папку проекта:**
```bash
git clone https://github.com/lumacya/antresol-analytics
cd /папка/куда/склонировали
```

**2. Настройте переменные окружения:**
Скопируйте шаблон файла конфигурации. При необходимости откройте `.env` и измените дефолтные пароли и порты.
```bash
cp .env.example .env
```

**3. Установите зависимости:**
Проект использует `uv` для управления пакетами. Зависимости описаны в `pyproject.toml`, а их строгие версии зафиксированы в `uv.lock`. Следующая команда автоматически создаст виртуальное окружение (`.venv`) и установит все необходимые пакеты:
```bash
uv sync
```

**4. Поднимите инфраструктуру (Базу Данных):**
Одной командой запустите Docker-контейнер с PostgreSQL. При первом запуске база данных будет инициализирована, и автоматически выполнится скрипт, создающий read-only роль `analyst`.
```bash
make up
```
*(База данных поднимется в фоновом режиме, а данные будут сохраняться в папку `data/` в корне проекта).*

**5. Проверка работоспособности (Smoke Test):**
Чтобы убедиться, что база данных работает и Python корректно к ней подключается:
1. Откройте проект в **VSCode**.
2. Перейдите в папку `notebooks/` и откройте ноутбук `00_smoke_test.ipynb`.
3. В правом верхнем углу выберите ядро (Select Kernel) -> **Python Environments** -> выберите виртуальное окружение **`.venv`**, которое создал `uv`.
4. Нажмите **"Restart & Run All"**.

Если все ячейки выполнились без ошибок — окружение полностью готово к работе! 🎉

---
**Полезные команды (Makefile):**
* `make up` — поднять инфраструктуру.
* `make down` — остановить контейнеры (данные в БД сохранятся).
* `make psql` — быстро зайти в консоль БД от имени администратора.
* `make lint` — запустить все проверки кода (Ruff, SQLFluff, Gitleaks) через pre-commit.
